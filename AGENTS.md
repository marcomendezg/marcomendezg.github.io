# Personal website conventions

- Links to external websites must use `target="_blank" rel="noopener noreferrer"`, including paper titles, journal citations, arXiv links, talk recordings, and profile links.
- Internal navigation and links within guaraco.com stay in the current tab. Leave `mailto:` and other non-web links to their normal handlers.
- Apply this convention to new pages and templates, including standalone arXiv summary pages.

- Use “Marco A. M. Guaraco” consistently as the website’s display name and in search metadata.
- Show changes in the local preview first. Do not push or publish changes until Marco explicitly approves publishing them.
